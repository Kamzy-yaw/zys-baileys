# ZysBaileys Documentation

Use these guides for the experimental message features and for migrating an existing Baileys project.

| Guide | Description |
| --- | --- |
| [Rich Response](rich-response.md) | Structured text, code, tables, and links. Experimental; rendering may vary by WhatsApp client. |
| [HTML App](html-app.md) | HTML markup packaged in a message. Experimental; Android rendering for this implementation is unverified. |
| [Native Flow](native-flow.md) | Native-flow quick-reply message structure. Experimental; successful rendering and interaction are unconfirmed. |
| [Migration Guide](migration.md) | Installation, core API usage, compatibility caveats, and migration checks. |

See each feature guide for its API details, examples, and limitations.
